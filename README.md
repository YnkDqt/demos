# Démos

Application web citoyenne qui décrypte la politique française.

## Démarrage

```bash
npm install
npm run dev
```

App disponible sur `http://localhost:5173`.

## Build prod

```bash
npm run build
npm run preview
```

## Données

Voir `scripts/README.md`. Les JSON sont générés via scripts Node et commitables dans `public/data/`.

## Stack

React 18 · Vite · Recharts · Vercel · Mono-fichier `src/App.jsx`.
